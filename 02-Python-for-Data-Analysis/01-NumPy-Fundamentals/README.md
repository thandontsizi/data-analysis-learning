# NumPy Fundamentals:

## Section Overview:
This section focuses on **NumPy**, a fundamental Python library for numerical computing. The goal is to learn how to create, manipulate, and analyse numerical datasets efficiently using arrays. NumPy is treated here as a data analysis tool, not as a general-purpose Python library.

---

## Objectives:
By the end of this section, I aim to:
- Understand how to create and manipulate 1D and 2D arrays.
- Perform element-wise operations and use aggregation functions ('sum()', 'mean()', 'median()', 'max()', and 'min()').
- Access, slice, and modify subsets of array data.
- Apply NumPy arrays in analysis workflows including preparation for visualisation.
- Integrate NumPy with other Python libraries like pandas and matplotlib.

---

## Core Concepts Covered:
- Creating arrays from Python lists or built-in functions.
- Array operations and broadcasting.
- Indexing and slicing 1D and 2D arrays.
- Aggregation functions for summarising data.
- Working with 2D arrays/matrices (rows, columns, subarrays).
- Using NumPy arrays in Python-based analytical workflows.

---

## Expected Outcome:
After completing this section I will be able to:
- Apply NumPy operations to solve practical data analyisis problems.
- Summarise, manipulate, and transform numerical datasets efficiently.
- Use arrays as a foundation for more advanced Python-based analysis and visualisation.
