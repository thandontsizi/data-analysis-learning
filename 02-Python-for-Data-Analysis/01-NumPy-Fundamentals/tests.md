# NumPy Tests:

## Basic Exercises:
1. Create a NumPy array with the values [10, 20, 30, 40, 50].
	- Print the array.

2. Multiply the array [1, 2, 3, 4] by 3.
	- Print the result.

3. Create an array from 10 to 50 with a step of 5 using NumPy.
	- Print the array.

## Scenario-Based Questions:
1. **Sales Data Analysis:**
You are given daily sales figures: [120, 150, 200, 170, 90, 300, 250]
- Calculate the total sales for the week.
- Find the average daily sales.
- Identify the highest and lowest sales days.
- Multiply all values by 1.1 to simulate a 10% increase.

2. **Student Scores:**
A class has the following test scores: [55, 70, 65, 80, 90, 50, 75]
- Calculate the average scores.
- Find how many students scored above the average.
- Extract all scores greater than 70.

3. **Temperature Monitoring:**
You are tracking hourly temperatures: [22, 24, 19, 21, 25, 27, 23, 20]
- Find the highest and lowest temperatures.
- Calculate the average temperature.
- Extract temperatures above 23 degree.

4. **Dataset Preparation:**
You are preparing data for analysis:

Dataset:
[[1, 200],
 [2, 150],
 [3, 300],
 [4, 250]]

(First column = ID, Second column = Value)
- Extract only the values column.
- Calculate the total and average of the values.
- Identify the row with the highest value.
