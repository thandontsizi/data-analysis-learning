# Pandas Fundamentals:

## Objective:
This section focuses on learning pandas as the primary tool for data analysis in Python.

The goal is to become comfortable working with tabular data including loading, inspecting, cleaning, and analysing datasets.

---

## Focus:
- Working with DataFrames.
- Inspecting dataset structure.
- Handling missing values.
- Filtering and selecting data.
- Grouping and aggregation.
- Writing clear and readable code.

---

## Folder Structure:
- **commands.md:**
	- Common pandas operations and syntax.

- **tests.md:**
	- Practice questions to reinforce understanding.

- **practice/:**
	- Small exercises and datasets.

---

## Approach:
Learning is reinforced through:
- Writing code by hand.
- Practising common operations repeatedly.
- Applying concepts to small datasets.

---

## Outcome:
By the end of this section I should be able to:
- Work confidently with pandas DataFrames.
- Clean and prepare datasets.
- Perform basic analysis.
- Write clear and structured code.
