# Matplotlib Fundamentals:

## Overview:
Matplotlib is used to visualise data. It helps turn numerical results into charts that make patterns, trends, and comparisons easier to understand.

This section focuses on creating simple, clear visualisations that support data analysis.

---

## What is Covered:
- Line charts (trends over time).
- Bar charts (category comparison).
- Histograms (data distribution).
- Titles, labels, and basic formatting.

---

## Role in Analysis:
Visualisation comes after data preparation and analysis.

Typical flow:
1. Clean and prepare data.
2. Analyse data (pandas/NumPy).

Charts are used to **support and communicate insights**, not replace analysis.

---

## Approach:
- Use small datasets.
- Build charts step-by-step.
- Focus on clarity over complexity.

The key question:
- What does this chart show?

---

## Outcome:
After this section, I should be able to:
- Choose the right chart for the data.
- Create clear, readable visualisations.
- Use charts to explain analytical results.
