# Database Integration (Python + PostgreSQL):

## Objective:
Build a clear understanding of how Python interacts with a PostgreSQL database using 'psycopg2'. Tha goal is to move beyond standalone scripts and begin working with real data stored in a database using Python to automate querying, insertion, and basic data workflows.

---

## Focus:
This section concentrates on the core building blocks of database interaction:
- Establishing and managing database connections.
- Executing SQL queries from Python.
- Inserting and retrieving data.
- Understanding transactions (commit and rollback).
- Writing safe queries using parametrisation.
- Handling errors in a controlled and predictable way.

The emphasis is not on syntax, but on understanding how these pieces work together in practice.
