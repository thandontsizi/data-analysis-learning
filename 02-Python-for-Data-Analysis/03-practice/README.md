# Practice Exercises: Data Analysis Fundamentals.
This folder contains **practice datasets and exercises** designed to reinforce core Python and data analysis skills. It complements the main learning modules by providing hands-on, realistic tasks where techniques can be applied in a safe, experimental environment.

---

## Folder Structure:
```bash
../03-practice
├── 01-practice-analysis-project
│   ├── 01_data
│   │   ├── dataset_1.csv
│   │   ├── dataset_2.csv
│   │   └── ... (other practice datasets)
│   ├── 02_analysis
│   │   ├── 01_dataset_audit.py
│   │   ├── 02_findings.md
│   │   ├── 03_dataset_cleaning.py
│   │   ├── 04_eda.py
│   │   └── 05_analysis.py
│   └── 03_results
│       └── 06_reflections.md
└── README.md
```

---

## Guidelines:
- **Data Files:** All raw practice datasets live in '01_data/'.
- **Analysis:** Scripts, notebooks, or folders with step-by-step analysis are in '02_analysis/'.
- **Results:** Outputs, charts, and insights go under '03_results/'.

---

## Purpose:
The practice folder is **not part of the main portfolio**. It is a sandbox to:
- Explore new datasets.
- Test Python, Pandas, NumPy, and visualisation techniques.
- Strengthen analytical thinking and debugging skills.
- Prepare for project work without affecting recruiter-facing projects.
