## Scenario-Based Questions:
1. **Monthly Sales Trend:** 
You are given monthly sales data: 
[100, 150, 200, 250, 300, 280]

- Plot a line chart showing the trend.
- Add appropriate labels and a title.
- Describe the trend in one sentence.

2. **Product Comparison:** 
You are comparing product sales: 

Products: ['Product A', 'Product B', 'Product C'] 
Sales: [120, 90, 150] 

- Create a bar chart.
- Identify which product performs best.
- Explain what the chart shows.

3. **Customer Distribution:** 
You are given customer purchase counts: 
[1, 1, 2, 2, 2, 3, 3, 4, 5, 5, 5, 5]

- Create a histogram.
- Identify the most common purchase frequency.
- Explain what the distribution suggests.

4. **Analysis Output Visualisation:** 
You previously calculated revenue using Python/NumPy: 
[200, 250, 300, 280, 320]

- Plot the results using a line chart.
- Add labels and a title.
- Explain what the chart communicates.
