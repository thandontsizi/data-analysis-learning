# Visualisation Practice:

## Purpose:
This folder contains practice exercises focused on building and improving data visualisation skills.

The goal is to become comfortable translating data into clear and meaningful visual representations.

---

## Folder Structure:
Each folder represents a focused visualisation exercise such as:
- Basic plots.
- Time series visualisation.
- Comparison charts.

---

## Approach:
Practice focuses on:
- Plotting clean and readable charts.
- Understanding what each visual communicates.
- Improving clarity and representation.

---

## Notes:
- These exercises focus only on visualisation.
- Data used here is assumed to already be cleaned.
- Full analysis workflows are handled in the [Python practice section](../../02-Python-for-Data-Analysis/03-practice).
