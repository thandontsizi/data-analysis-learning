# Data Visualisation:

## Objective:
This section focuses on learning how to represent data visually using Python.

The goal is to move from raw analysis to clear and interpretable visual outputs that support understanding and communication.

---

## Folder Structure:
- **01-Matplotlib-Fundamentals:**
	- Core plotting concepts and syntax.
	- Commands and exercises.

- **02-practice:**
	- Hands-on visualisation exercises.
	- Focused on plotting, trends, and presentation.
	- Does not include full data cleaning workflows.

---

## Focus:
- Plotting data using Matplotlib.
- Understanding trends visually.
- Choosing appropriate chart types.
- Writing clear and readable visualisation code.

---

## Approach:
Concepts are learned through:
- Fundamental exercises (Matplotlib).
- Focused visualisation practice (02-practice).

---

## Notes:
- Data preparation is handled in the Python section '02-Python-for-Data-Analysis'.
- This section focuses solely on visualisation.
- Project-based visualisations are included in the main portfolio repository.
