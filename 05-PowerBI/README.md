# Power BI Learning Folder:

## Overview:
This folder contains all learning material and practice exercises for Power BI, a business intelligence and data visualisation tool. Power BI is designed to help transform raw datasets into interactive dashboards and reports that communicate insights effectively.

The goal of this folder is to provide a structured approach to learning Power BI. From DAX fundamentals to creating dashboards while keeping practice exercises separate from polished portfolio work.

---

## Folder Structure:
- **01-DAX-Fundamentals:**
	- Core lessons on DAX formulas, measures, calculated columns, and tables. This is the Power BI equivalent of a "fundamentals" module in Python or SQL.

- **02-practice:**
	- Practical exercises and dashboard builds. Each subfolder contains one dashboard exercise with:
		- Source dataset ('.csv' or other formats).
		- Power BI file ('.pbix').
		- Notes and reflections ('notes.md').

- **Root Files:**
	- 'README.md': this file.
	- 'commands.md': Quick reference for DAX formulas, keyboard shortcuts, and Power BI tips.
	- 'tests.md': Small exercises to test understanding of DAX and basic dashboard creation.

---

## Learning Goals:
By working through this folder, I will be able to:
1. Understand the Power BI interface and workflow.
2. Write basic to intermediate DAX formulas for analysis.
3. Create calculated columns, measures, and tables.
4. Build visualisations and interactive dashboards.
5. Apply filters, slicers, and drill-through features effectively.
6. Document and reflect on my work for future portfolio use.

---

## Usage Notes:
- **Practice Only:** This folder is for learning and experimentation. Final polished dashboards go into the [portfolio repository](../../data-analysis-portfolio).
- **Consistency:** Follow the same naming conventions and folder structure as other learning modules.
- **Reflections:** After completing each dashboard, add observations and notes in 'notes.md' to capture lessons learned and challenges faced.
